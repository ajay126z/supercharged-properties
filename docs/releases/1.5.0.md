# Supercharged Properties 1.5.0

Requires Obsidian 1.7.2 or later. Works on desktop and mobile.

## Inline properties and saved inline views

Enable **Show inline properties** in settings to browse Dataview-style fields such as `author:: AJ` in a separate **Inline Properties** tree. Browse property → value → notes, filter by a value, and save inline views independently of YAML views. Dataview is not required. Link values, nested lists, and supported list continuations are recognized; frontmatter, code, and comments are ignored.

Right-click a property or value, or long-press on mobile, to rename properties, delete properties, rename values, or replace several selected values with one new text value. Edits require preview and confirmation and skip conflicting notes. **Undo last inline property edit** restores the last inline batch during the session. Inline pins and hidden properties are separate from YAML settings. Native Search uses text queries and can match more broadly than the inline parser.

## Convert inline fields to YAML

Choose **Convert to YAML property…** from an inline property or value menu. Choose notes, **Move** or **Keep** the source fields, and **Skip**, **Merge into list**, or **Overwrite** existing YAML values. Repeated fields become lists. Literal text is the default; optional detection handles numbers, booleans, and date-compatible ISO text.

Preview the frontmatter changes and removed body fragments before confirming. Folder and Value filters constrain eligible notes; tree search is display-only. Conversion shares **Undo last property edit** with YAML edits. Later edits are protected. Frontmatter and body use separate writes, so a partial failure may leave both forms present; affected paths are reported and an undo snapshot is retained where safe. YAML comments and quoting may change during conversion.

## Saved folder filters

Use **Choose properties to show → + Add folder** to include chosen folders and descendants. Remove individual chips or clear the folder bar. Folder filters combine with Value filters and narrow the tree, distinct-note counts, copied links, and edits. Global excluded folders always win.

Save folder selections with YAML or Inline views, including all-properties folder views. Built-in views and older folder-free views clear the current folder selection. Missing or excluded folders remain as muted chips for review; folder renames do not rewrite saved paths. **Open in Search** and **Copy search query** remain vault-wide.

## Browsing and view improvements

- Pin or unpin locally in a saved view while inheriting global pins from All properties.
- Keep search and filters when expanding or collapsing, with progressive property → value → note expansion after Collapse all.
- Update distinct-note counts and matching-note disclosures as search changes, regardless of the order in which filters were applied.
- Open the view picker downward with scrolling, wrapped names, and keyboard navigation.
- Disable hover hints with the **Show tooltips** setting while retaining accessible labels and note previews.

## Validation

The release candidate passes lint, TypeScript/build, all 387 automated tests, release validation, and documentation-link checks. Coverage includes folder matching, profile persistence, filter intersections, write-and-undo isolation, inline parsing, conversion conflicts, and shared busy protection. Simulated mobile-browser checks cover chip wrapping and conversion/save control reachability; on-device Obsidian QA remains recommended.

## Installation

Install `main.js`, `manifest.json`, and `styles.css` from the same release into `<YourVault>/.obsidian/plugins/supercharged-properties/`, then reload Obsidian. The release workflow builds and attests these three assets when the version tag is published.
