# Supercharged Properties 1.4.2

Requires Obsidian 1.7.2 or later. Works on desktop and mobile.

## Mobile notes open on tap

Restore normal note tapping in All Properties, custom saved views, and value-filtered views. The long-press handler no longer suppresses a tap when the touch pointer leaves after release. Long-press still opens the context menu, and scrolling still avoids accidental note opening.

## Open in Search works after vault startup

With core Search enabled, **Open in Search** now works even when the Search pane has not been opened during the current session. The plugin waits for Obsidian to load the pane before applying the query, avoiding the incorrect enable-Search notice on desktop and mobile.

## Validation

Lint, TypeScript/build, all 287 automated tests, release validation, and documentation link checks pass. Regression tests cover mobile taps across view modes, long-press and scroll suppression, and newly created or restored deferred Search panes. The tap fix was also checked with mobile-emulated Chrome; the Search fix was confirmed by the user.

## Installation

Download `main.js`, `manifest.json`, and `styles.css` into `<YourVault>/.obsidian/plugins/supercharged-properties/`, then reload Obsidian. GitHub Actions builds and attests these three assets during publication.
