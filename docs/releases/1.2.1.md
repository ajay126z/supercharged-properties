# Supercharged Properties 1.2.1

Released 2026-11-15. Requires Obsidian 1.7.2 or later.

## Mobile saved-view layout

Saved-view controls now stay reachable on small screens and above the on-screen keyboard. On touch and narrow layouts, the view name field and action buttons appear before the property choices, controls use larger touch targets, and the picker scrolls within the visible viewport. Opening the picker no longer opens the keyboard automatically.

Typing a name and using **Done/Enter** saves a new view without submitting during IME composition. Successful mobile actions dismiss the name-field keyboard when it still has focus.

## Saved-view protections

- **All** and **None** preserve a typed view name on desktop and mobile.
- **Save new** rejects an empty selection or the all-properties selection, and **Update** rejects the same selections without changing the saved view.
- **All properties** is the reserved name for the built-in default view, which cannot be renamed or deleted.
- Choosing All clears the active saved view, disables its Update/Rename/Delete controls, and leaves saved views intact.

## Validation

Lint, TypeScript/build, release validation, and 115 automated tests pass. Mobile behavior has jsdom and simulated browser coverage; live Obsidian iOS/Android QA was not performed in this session.

## Attested release assets

GitHub Actions builds, attests, and verifies the release before publication. Only `main.js`, `manifest.json`, and `styles.css` are attached. Use `gh attestation verify <file> --repo ajay126z/supercharged-properties` to verify a downloaded asset.

## Installation

Copy the three attached assets into `<YourVault>/.obsidian/plugins/supercharged-properties/`, then reload and enable the plugin. Minimum Obsidian version remains 1.7.2.
