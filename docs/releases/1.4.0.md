# Supercharged Properties 1.4.0

Requires Obsidian 1.7.2 or later. Works on desktop and mobile.

## Explore notes sharing a value

Right-click a value on desktop or long-press it on mobile, then choose **Filter by this value**. For example, filter `status = active` to see which authors, topics, and priorities occur among active notes.

- Counts and copied note links describe only matching notes.
- The filter property is hidden from the tree and picker, while the filter bar keeps its context visible.
- Results update as notes change. If no notes match, the condition stays visible and clearable.
- Each tab has one independent filter. Choosing another replaces it; recreating the view or reloading the plugin clears it. Saved views retain their full property selections.
- The `(empty)` value is supported. Counts represent distinct notes, including after repeated metadata updates and renames.

**Clear** returns to the full tree. Tree search and saved views continue to control which branches are displayed. **Open in Search** and **Copy search query** remain vault-wide and do not include the Value filter.

## See and open matching notes

Expand the note count in the filter bar to see a scrollable list of matching note names and folders. Open a note with a click or tap, or use Ctrl/Cmd-click to open a new tab. The list follows Obsidian's opening modifiers and supports desktop hover previews through the Page preview core plugin and its settings.

Names sort alphabetically with numeric ordering. The list initially loads up to 200 notes; **Show more** loads additional batches. Tree search does not narrow this list. Live updates preserve scroll and keyboard focus where possible.

Use ArrowDown from the count button to enter the list, Up/Down or Home/End to navigate, Enter to open, and Escape to collapse. Applying another filter or clearing it resets the list.

## Edits respect the filtered group

Value edits, property-name renames, and property deletions started from the filtered tree affect only matching notes in the subset. Merge targets come from values present in that group. Preview, confirmation, conflict checks, and **Undo last property edit** remain available. Inspect the affected paths before applying an edit.

## Mobile layout

Long property names and values wrap in the filter bar. The note-count and Clear buttons stay together and move below the label when needed. Expanded notes use larger touch targets and a scrollable area that leaves space for the toolbar and property tree on short screens.

The README and user guide include a new GIF demonstrating filtering, revealing matching notes, opening a note, and clearing the filter.

Lint, TypeScript/build, release checks, and 278 automated tests pass. Browser fixtures cover desktop, narrow mobile widths, and reduced keyboard-height layouts. Physical-device QA remains a manual release check.

## Installation

Download `main.js`, `manifest.json`, and `styles.css` from this release into `<YourVault>/.obsidian/plugins/supercharged-properties/`, then reload Obsidian and enable the plugin. These are the only release assets; GitHub Actions builds and attests them during publication.
