# Supercharged Properties 1.4.1

Requires Obsidian 1.7.2 or later. Works on desktop and mobile.

## Clearer menu label

The value-row action is now called **Filter by Value**, replacing **Filter by this value**. Right-click a value on desktop or long-press it on mobile to use it. Filtering behavior is unchanged.

The README, user guide, and demo GIF now show the updated label.

## Validation

Lint, TypeScript/build, all 278 automated tests, release validation, and documentation link checks pass.

## Installation

Download `main.js`, `manifest.json`, and `styles.css` into `<YourVault>/.obsidian/plugins/supercharged-properties/`, then reload Obsidian. GitHub Actions builds and attests these three assets during publication.
