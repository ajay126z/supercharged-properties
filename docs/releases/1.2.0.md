# Supercharged Properties 1.2.0

Released 2026-11-15. Requires Obsidian 1.7.2 or later.

## Rename property names

Right-click a property row and choose **Rename property…** to rename keys across matching notes. Review the full preview and skipped-note list before confirming. Case-only corrections are supported; stored values and types are preserved. Destination collisions, ambiguous keys, and notes changed since preview are skipped.

Saved views and display preferences include the new key while retaining the old one for skipped notes and undo. Obsidian's configured property types, templates, and queries are not renamed.

## Exclude folders

Use **Settings → Supercharged Properties → Excluded folders** to keep template notes or other folders out of the tree. Enter one case-sensitive, vault-relative folder path per line. Descendants are included, while similarly named sibling folders remain visible.

Changes apply immediately to properties, counts, local search, copied note links, and new bulk edits. Previously opened previews also skip newly excluded notes. Undo remains available for earlier edits. Obsidian's core Search is independent of these exclusions.

## Text-only splitting

**Split into list…** is now offered only for text values under Text properties. It is hidden for List, Number, Checkbox, Date, Date & Time, tags, aliases, and cssclasses. The built-in special names remain ineligible even with a Text override. Existing list values are not split again.

## Shared undo and other fixes

- **Undo last property edit** shares one undo slot across property-name and value edits. The existing command ID is preserved for hotkeys.
- Undo skips later changes, lasts until plugin reload, and is replaced by the next successful batch. It restores keys and values, not YAML formatting.
- UI elements use Obsidian's native helpers; CSS no longer uses `!important`.
- User documentation now covers every feature, operation scope, and recovery limit.

## Attested release assets

GitHub Actions builds, attests, and verifies the release before publication. Only `main.js`, `manifest.json`, and `styles.css` are attached. Use `gh attestation verify <file> --repo ajay126z/supercharged-properties` to verify a downloaded asset.

## Installation and validation

Copy the three attached assets into `<YourVault>/.obsidian/plugins/supercharged-properties/`, then reload and enable the plugin. Minimum Obsidian version remains 1.7.2.

Lint, TypeScript/build, release validation, and 103 automated tests pass. Live Obsidian desktop/mobile QA was not performed in this session.
