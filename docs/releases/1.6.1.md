# 1.6.1 — Compatibility and privacy documentation

This patch addresses two compatibility warnings and clarifies data access. No visible or functional change is expected; the minimum Obsidian version remains **1.7.2**.

## Compatibility fixes

- Use legacy rectangular clipping for visually hidden screen-reader announcements instead of `clip-path`, preserving accessibility.
- Remove a `globalThis` type reference from progressive search rendering. The renderer continues to use its pane’s owning window for observers and animation frames, with regression coverage for a separate window context. The type change does not alter the generated JavaScript.

## Data access explained

The README and [user guide](../USER-GUIDE.md#data-access-and-privacy) explain why the plugin lists Markdown note paths, how exclusions apply, and when optional File explorer counts include attachment paths. Counting does not read file contents.

Clipboard access is write-only and occurs when you choose a Copy action. The plugin does not read or monitor your clipboard. Generic scanner capability recommendations may still appear; this release documents their purpose rather than removing these features.
