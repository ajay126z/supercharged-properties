# Supercharged Properties 1.3.0

Requires Obsidian 1.7.2 or later. Works on desktop and mobile.

## Change values on selected notes

Update one note or several notes directly from the property tree. Right-click a note on desktop or long-press on mobile, then choose **Change status…** (the action uses the property's name). Choose **Select notes…** to edit several notes within the same property, including notes in different value groups.

- **Text:** choose an existing value or enter new text.
- **Number:** enter a number with validation.
- **Checkbox:** choose checked or unchecked.
- **Date and Date & time:** use typed controls to choose a date or local timestamp.
- **List:** add or remove multiple text or number items while preserving other items. Aliases and cssclasses support text items; tags are excluded from selected-note editing.

Selection checkboxes and highlighted rows appear on desktop and mobile. Desktop supports Alt/Option-click to toggle individual notes, Shift-click to add a displayed range, Shift+Up/Down to extend selection, and Escape to clear it. Mobile uses long-press menus and tap-to-toggle selection.

The mobile change dialog uses the available screen space, scrolls its content, and keeps confirmation buttons above the keyboard.

## Clear a value or remove the property

**Set empty (keep property)** retains a scalar key with a null value. **Remove property** deletes the entire key and value from selected notes. For lists, **Remove values** removes only the chosen items and leaves an empty list when the final item is removed. **Remove property** deletes the whole list and key, whether it has one item, several items, or no items.

Property-row and value-row menus also offer deletion across matching notes. Note selection limits only the note-row editing action; it does not narrow these bulk actions.

## Preview, confirmation, and undo

Review before/after values and affected paths before confirming an edit. Conflicting property names, changed values, and newly excluded notes are skipped. Whole-property removal has an explicit removal confirmation.

Use **Supercharged Properties: Undo last property edit** to restore the last successful batch. Undo preserves later conflicting edits, including keys recreated after deletion. Property deletion retains saved views, pins, and other display preferences. Undo lasts until another successful edit or plugin reload and restores values rather than original YAML formatting.

## Installation

Download `main.js`, `manifest.json`, and `styles.css` from this release into `<YourVault>/.obsidian/plugins/supercharged-properties/`, then reload Obsidian and enable the plugin. These are the only release assets; GitHub Actions builds and attests them during publication.
