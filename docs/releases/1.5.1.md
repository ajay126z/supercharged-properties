# Supercharged Properties 1.5.1

## Filename sorting

A–Z and Z–A now sort linked property values by the target note’s basename, rather than the raw wikilink label. Aliases, folder paths, headings, and block references do not affect this order. Resolved links use the actual note filename; unresolved links fall back to the final target segment without `.md`.

Expanded notes use the same natural filename ordering as the filtered-note list, with the full vault path as a tie-breaker. For example, `2026-W9` sorts before `2026-W21`. Z–A reverses the tree ordering. Original value labels and editing behavior are preserved, and frequency sorting remains unchanged.

## Cleaner folder-filter controls

Folder chips and Clear now stay inside **Choose properties to show**. Closing that panel hides the folder paths while keeping filters and summary counts active in YAML and Inline views.

## Validation

- 391 automated tests pass.
- Lint, TypeScript build, release assets, and local Markdown links validated.

The multi-property batch editor remains on its separate feature branch and is not part of this release.
